# LearnFlow

**个性化 AI 学习规划与知识管理智能体**。LearnFlow 面向每天接触大量学习材料的学习者，将「信息筛选 → 学习任务 → 进度跟踪 → 复习检验」连接成一个可持续的学习闭环。

## MVP 功能

- 学习画像：学习目标、当前水平、每日时间和已有知识。
- 信息筛选：粘贴文章/课程笔记，按当前目标给出相关度、优先级、推荐理由、摘要、关键知识点和行动建议。
- 学习计划：将建议转成待开始、进行中、已完成的任务。
- 复习中心：将知识点转成问答卡；记住了则 3 天后复习，还不熟则次日复习。
- 操作记录：记录材料筛选、任务变更和复习打卡，便于检查系统行为。
- 离线演示模式：未配置 API Key 时可以体验基本流程，但材料相关度来自简单关键词启发式，不能等同于真实的 LLM 语义分析。

## 快速启动（Windows PowerShell）

```powershell
conda create -n learnflow python=3.11 -y
conda activate learnflow
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

打开 `.env`，填写 `DEEPSEEK_API_KEY`。`MODEL_ID` 可按你的 API 账号可用模型调整。然后运行：

```powershell
streamlit run app.py
```

如果已经有可用的 Conda 环境，也可以在该环境中安装 `requirements.txt`，无需新建环境。

## 演示流程

1. 在左侧设置学习目标，例如「掌握 Python 与 AI Agent 开发」。
2. 在“信息筛选”粘贴一段课程材料或技术文章，分析它与当前目标的相关性。
3. 检查 AI 的推荐理由与摘要，再将学习动作加入计划。
4. 将关键知识点生成复习卡，在“复习中心”测试自己。
5. 查看操作记录，解释材料筛选、任务更新和复习打卡实际发生了什么。

## 技术架构

- 前端：Streamlit
- 推理：DeepSeek OpenAI-compatible Chat Completions API
- 本地数据：JSON 文件，便于 MVP 演示和检查
- 核心流程：用户画像 + 材料 → LLM JSON 评估 → 用户审查 → 学习任务/复习卡 → 操作记录

## 安全与局限

- 不要将 `.env` 或任何 API Key 上传到 GitHub。
- 当前应用只处理用户粘贴的文本，不会自动抓取网页，也不提供向量检索。
- JSON 文件适用于个人 MVP，不适合多用户并发、复杂权限和高可用场景。
- 相关度、摘要和复习题由模型生成，可能出错；请用户复核，不把模型评分当作客观真理。
- 当前复习间隔是透明的简化规则（掌握后 3 天、未掌握则 1 天），尚不是经实证验证的自适应算法。
- 操作记录记录本地应用事件，不等同于完整的底层 API/系统级审计日志。
